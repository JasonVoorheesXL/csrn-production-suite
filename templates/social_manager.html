Game Story

Pick the article and who writes it. Read it, change anything you like, then post it.
The AI writer needs your station's Anthropic API key

It's a one-time setup, about five minutes, and you do it on Anthropic's site:

  1. Go to console.anthropic.com and create an account, or sign in.
  2. Open Billing and add a few dollars of credit. The AI writer is billed there, separately from any Claude subscription: a few cents per story.
  3. Open API Keys, click Create Key, give it a name like "Game stories", and copy the key. It starts with sk-ant-, and Anthropic shows it only once.
  4. Come back here, click Paste my key, paste it, then click Save key and Test key.
Until then, the app writes the stories itself.
