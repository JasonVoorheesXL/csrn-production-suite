# CSRN Engine Architecture v1.0

## Current engines
- Roster Engine v1.1
- Personnel Engine v1.0
- Graphics Engine v2.2
- Graphics Library v1.0
- Asset Manager v1.0
- Sponsor Engine v1.0

## Core rules
1. Runtime data remains outside Git history.
2. Assets are stored once and referenced by stable asset IDs.
3. Primary identification graphics are mutually exclusive.
4. Scorebug and ticker remain independent persistent channels.
5. Engine changes are versioned and documented.
