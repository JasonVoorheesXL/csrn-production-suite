# Broadcast Automation Engine — Operator Notes

## Number-first lookup
Press the event button under the correct team, then enter the player's jersey number. The engine searches that team's linked roster automatically.

- One match: player information loads automatically.
- Multiple matches: select the correct player.
- No match: use the temporary player fallback. The default name is `Team Name + jersey number`, and the default position is `ATH`.

## Scoring controls
- TD: Rush, Reception, Return, or Other.
- FG: Kicker number; Statistician Mode may add distance.
- XP: Kicker number.
- 2PT: Rush, Reception, Return, or Other; receiving conversions allow a passer number.
- Turnover: Interception, Fumble Recovery, Downs, or Other; return touchdowns may be recorded.
