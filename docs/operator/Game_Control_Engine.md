# Game Control Engine — Operator Notes

## Penalties
Choose the team, unit, foul, yardage, and ruling. Accepted offensive fouls normally add the enforcement yardage to the distance and replay the down. Accepted defensive automatic-first-down fouls set 1st & 10. Declined, offsetting, and flag-picked-up rulings are logged without yardage enforcement.

## Quick Correct
Use Quick Correct whenever the officials place the ball differently from the calculated result. Set down, distance, ball spot, possession, and quarter, then add an optional note.

## Edit Play
Open the Statistician Play Register and select Edit. Correct yards, description, quarter, or the resulting game state without undoing and re-entering the play.

## USB Tethering
Connect the phone by USB and enable USB tethering. Open Mobile / USB Connection and refresh addresses. A second phone or tablet should open one of the listed URLs. Some phones cannot browse back to the laptop while they are the tethering device.
