# Broadcast Package Engine

1. Open **Broadcast Packages**.
2. Select **Create Package**.
3. Link an existing Game Manager broadcast.
4. Select rosters, personnel, and active sponsors.
5. Review Package Health.
6. Save, then choose **Load Package** to populate Command Center state.
7. Lock the package after final game-day review.

## Starting Lineup Manager

Each broadcast package can store separate Home and Visitor starting lineups for Offense, Defense, and Special Teams.

- Link the appropriate roster to the package.
- Choose Home or Visitor and select the roster source.
- Apply a preset or add custom position slots.
- Position names remain fully editable for formations such as 4-2-5, two-back sets, or unusual special-teams arrangements.
- Assign active roster players to each slot.
- Reorder or remove slots without changing the master roster.

Personnel inclusion is package-specific. Unchecking a crew member removes that person from the current broadcast package only; the Personnel Engine record remains intact.
