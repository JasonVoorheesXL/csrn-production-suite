# Statistician Console v1

## Enable
Open Command Center and select **Enable Statistician Console**.

## Authority
Only the active authority may publish game data. With Statistician active, broadcaster controls are locked. Production graphics unrelated to game data remain available.

## 1st Down
Selecting **1st Down** records an event and updates the scorebug to **1st & 10**.

## Penalty
The broadcaster receives a quick team penalty control. The statistician selects the unit, foul, and yardage. Version 1 does not yet enforce the ball or automatically resolve accepted, declined, or offsetting penalties.

## Takeover
Use **Broadcaster Takeover** if the statistician console becomes unavailable. Existing game state is preserved.
