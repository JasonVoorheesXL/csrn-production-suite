# Broadcast Automation Engine — R2 Operator Notes

Select a team event button, then choose the jersey number from the scrollable list. Roster jersey numbers appear first, followed by all remaining values from 0 through 99.

For receiving touchdowns and two-point conversions, enter the passer number when prompted. Statistician Mode adds yardage to Event History, the viewer ticker, and the automated player graphic.

The event dialog scrolls independently from the Command Center. Confirm and Cancel remain available at the bottom of the dialog.
