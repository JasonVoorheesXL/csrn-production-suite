# 1.13.0-alpha.3c — NFHS Field Direction Hotfix

This build identifies the current football product as the NFHS edition. Future NCAA, NAIA, NJCAA, or other editions should be produced from the same shared application core with edition-specific rules modules and licensing.

## Changes

- Direction badges now travel with every field-position slider at one-yard precision.
- Badge text uses the configured team abbreviation and current drive direction.
- NFHS normal kickoffs default to the kicking team's own 40-yard line.
- Kickoff and punt forms no longer reveal Receiver Jersey; Returner Jersey handles all receiving situations.
