# Version 1.12.1c Hotfix — Statistician State Synchronization

## Fixed
- Statistician Current Down buttons now have the required state container and data values, so the selected down remains highlighted.
- First Down actions now refresh the Statistician Console from the authoritative server state immediately after the event is recorded.
- Statistician state changes, Undo, Quick Correct, event edits, and ejections now use a shared authoritative refresh path.
- Possession and down highlights are reapplied after each successful game-state mutation.

## Preserved
- Version 1.12.1a network detection, QR connection, and role selection.
- Version 1.12.1b console switcher and operator workflow cleanup.
- Version 1.12 penalty, Undo, editing, correction, and authority behavior.
