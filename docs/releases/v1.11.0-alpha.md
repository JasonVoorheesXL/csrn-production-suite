# Version 1.11 Alpha — Statistician Console v1

This release establishes the single-authority game-data architecture. When Statistician Console is active, broadcaster game-data entry is rejected by the backend and visibly locked in the Command Center. The statistician publishes scoring, turnover, possession, down/distance, 1st Down, and penalty events to the same event stream already consumed by the scorebug, event history, ticker, graphics, and Statistics Engine.
