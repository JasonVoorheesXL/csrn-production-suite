# Version 1.13.0-alpha.3g — Database Integrity Recovery

This stabilization build protects the persistent roster database during upgrades and routine writes. At startup and on roster access, the suite checks whether the active roster database contains players. If it is empty or invalid, it searches upgrade backups and prior installation folders for the most complete `rosters.json`, restores it, and writes a recovery report to `Data/Logs/roster_recovery.json`.

Every subsequent roster save creates a timestamped snapshot under `Data/Backups/RosterSnapshots`.

Recovery cannot recreate roster records if no surviving backup or prior installation contains them.
