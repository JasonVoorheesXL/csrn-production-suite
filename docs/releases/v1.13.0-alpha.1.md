# CSRN Production Suite v1.13.0-alpha.1 — Foundation

## Scope
- Introduces a centralized browser-side GameStateManager mutation and refresh pipeline.
- Locks broadcaster score and game-data controls while Statistician authority is active; clock visibility remains available.
- Locks all Statistician controls, including distance selection, when Statistician authority is inactive.
- Adds a persistent authority status banner and lock notice.
- Expands ticker controls with Very Slow, Slow, Normal, and Fast distance-based speeds plus loop pause configuration.
- Changes the default ticker preset to Slow with a two-second pause.

## Upgrade note
This is a source-update package. Preserve the installation Data directory, security.json, and state.json when applying it.
