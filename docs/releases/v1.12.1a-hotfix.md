# Version 1.12.1a Hotfix — Broadcast Network Manager

This focused hotfix starts from the validated Version 1.12 Alpha Game Control Engine baseline.

## Included

- Current IPv4 address discovery for Wi-Fi, iPhone hotspot, Ethernet, and USB tethering.
- Large QR code on Command Center that always uses the currently detected address.
- Refresh Network and Copy controls.
- Device role landing screen for Broadcaster, Statistician, and Read-Only Monitor.
- Statistician and Statistics navigation moved next to Command Center.
- Conservative button text sizing and wrapping improvements.

## Deliberately excluded

The broader Statistician play-entry, clock, event-regeneration, and ticker-expiration changes from the withdrawn 1.12.1 package are not included. They will be reintroduced separately after this network hotfix is validated.
