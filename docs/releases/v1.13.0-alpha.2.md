# CSRN Production Suite 1.13.0-alpha.2
## Play Register Foundation

This release establishes the canonical digital gamebook used by later statistics and drive-engine releases.

### Added
- Persistent `plays` collection alongside the existing event history.
- Unique sequential Play IDs scoped to the active broadcast.
- Structured records containing game context, result data, outcome flags, operator source, and future statistics/drive hooks.
- Backward-compatible migration for games created before Alpha.2.
- Selectable Play Register and read-only detail panel in the Statistician Console.

### Changed
- Linked play records now follow event edits and undo status.
- Ticker speed presets were doubled after Alpha.1 field testing showed every preset running at approximately half the desired pace.

### Compatibility
Existing Alpha.1 broadcasts remain loadable. Their event history is converted into play records when state is normalized.
