# CSRN Production Suite 1.13.0-alpha.3e

## Touchdown Trigger & Player Display Hotfix

- Rules-engine touchdowns now trigger the player touchdown graphic for the resolved scorer.
- Run touchdowns credit the ball carrier; completed-pass touchdowns credit the receiver.
- Canonical play events include touchdown, scoring, player, and media-trigger metadata.
- Existing jersey-only plays resolve names from the active roster at display time.
- Play Register list and detail views use the enriched canonical record.
