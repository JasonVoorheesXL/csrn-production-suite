# CSRN Production Suite

CSRN Production Suite is a proprietary broadcast production platform for scholastic athletics.

## Current operational build

- Google Drive working build: `1.13.0-alpha.8e`
- Current stage: release-candidate integration audit and controlled operational testing
- GitHub alignment branch: `audit/phase-6-12e-alignment`

The `main` branch began as the v1.5.0-alpha frozen baseline. Do not treat it as the current release source until the Drive working tree has been fully imported, tested, and reviewed.

## Product boundaries

- Windows host first; macOS host later.
- Phones, tablets, Chromebooks, and secondary computers use browser access.
- X remains assisted-manual only.
- No hosted AI or local AI is planned.
- Postgame articles use deterministic grounded generation.
